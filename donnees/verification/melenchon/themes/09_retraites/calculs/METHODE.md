# Méthode des calculs — Mélenchon, thème 9, Retraites et protection sociale

Résultats produits par `calculer.py` à partir de `brut/` (catalogue `sources.csv`), dans `resultats.csv`. Les règles
lues dans les documents sont dans `LUS`, avec la phrase exacte vérifiée. Données téléchargées le 21/11/2026.

## M1 — Âge légal et durée de cotisation (`RET-01`)

- Entrées : `SP-AGE-RETRAITE` (âge légal selon l'année de naissance) ; `SP-TRIMESTRES-TAUX-PLEIN` (trimestres exigés
  pour le taux plein). Calcul : 172 − 160 (40 annuités).
